# Personal Notebook App

A lightweight, web-based personal note-taking application designed to manage daily tasks and thoughts. This project demonstrates fundamental DOM manipulation, asynchronous data handling, and state management using vanilla web technologies.

## Features
* **CRUD Operations:** Create, read, update, and delete personal notes seamlessly.
* **Responsive UI:** Clean and intuitive user interface built with semantic HTML and plain CSS.
* **Dynamic Rendering:** Real-time UI updates using Vanilla JavaScript without relying on external libraries.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
